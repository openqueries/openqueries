# Provider icons

Shared, dependency-light React components for the provider marks shown by the
Open Queries website and Chrome extension.

The artwork follows the providers' published marks:

- [OpenAI design guidelines](https://openai.com/brand/)
- [Claude product icon](https://claude.ai/favicon.svg)
- [Google Brand Resource Center](https://about.google/brand-resource-center/brand-elements/)

Open Queries is independent and is not affiliated with, endorsed by or
sponsored by OpenAI, Anthropic or Google. Their names and marks remain the
property of their respective owners.
